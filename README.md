# 连锁便利店周销量 Holt–Winters 预测与回测平台

面向补货计划员的内部网页工具：上传/选择周销量序列 → 后台拟合 Holt–Winters
（加法/乘法季节，趋势可选「无 / 加法 / 加法阻尼」）→ 页面查看拟合曲线、
未来若干周点预测与预测区间 → 滚动原点回测并与**季节朴素法**对照。
数值内核（递推、优化、区间、回测）全部手写，仅依赖 NumPy，**不调用**
statsmodels 等现成实现。

- 后端：Python 3.12 + FastAPI + SQLAlchemy + PostgreSQL 16
- 前端：React 18 + Vite + TypeScript + Recharts
- 后台任务：有界线程池（`app/jobs.py`），多计划员处理不同序列互不阻塞
- 编排：`docker compose` 三服务（db / backend / frontend(nginx:1.27-alpine)）

## 一键启动

```bash
docker compose up --build
# 浏览器打开 http://localhost:8080
```

首次启动后端会等待数据库就绪并自动建表。示例数据：
`sample_beverage_sales.csv`（164 周、带夏季高峰与节假日峰值）。

## 页面说明

1. **序列列表**：上传 CSV（两列：周起始日期、销量）。日期按 7 天步长
   校验；缺周会列出具体日期并在序列上打标记（不阻止导入，建模按下文
   「缺周」一节处理）；非整周对齐（间隔不是 7 的整数倍）直接阻止导入
   并提示原因。
2. **拟合页**：
   - 原始值、拟合值、未来点预测与置信带同图展示；
   - 参数面板可勾选**锁定 α/β/γ/φ** 中任意若干个（手填数值），其余照常
     自动优化，点击后立即在后台重算；
   - 展示参数、SSE、AIC、残差（标准差等）、最终状态；
   - 自动选型时列出全部 6 种组合的 AIC/SSE/参数/可行性（评分卡），
     最优组合标星；
   - 同一序列的每次拟合都入库，可在底部列表中单选比较。
3. **回测页**：设置首个原点、步长 h、原点步长、置信水平与区间方法；
   逐原点列出 MAE/MAPE/MASE，并与季节朴素法并排，表格汇总 + 单原点
   逐步对照。页面所有数字均由后端计算。

所有计算在后台任务中执行，页面显示进度条与阶段；任务结果（拟合/回测）
落 PostgreSQL，可重复查看与比较。

## 模型定义（与代码一一对应）

记水平 `l_t`、趋势 `b_t`、季节指数 `s_t`，季节周期为 `m`（周数据默认 52）。

**加法季节**

```
ŷ_t = l_{t-1} + φ b_{t-1} + s_{t-m}
l_t = α (y_t - s_{t-m}) + (1-α)(l_{t-1} + φ b_{t-1})
b_t = β (l_t - l_{t-1}) + (1-β) φ b_{t-1}
s_t = γ (y_t - l_t) + (1-γ) s_{t-m}
```

**乘法季节**（加法式同上改为比值：`ŷ_t=(l_{t-1}+φb_{t-1})s_{t-m}`，
`l_t=α y_t/s_{t-m}+(1-α)(l_{t-1}+φb_{t-1})`，
`s_t=γ y_t/l_t+(1-γ)s_{t-m}`）。

`φ=1` 对应无阻尼；趋势选「无」时没有 `b` 与 `β`。

候选组合共 6 种：趋势 ∈ {无, 加法, 加法阻尼} × 季节 ∈ {加法, 乘法}。

### 参数取值区间（优化约束）

| 参数 | 含义 | 区间 |
|---|---|---|
| α | 水平平滑 | [0.001, 0.999] |
| β | 趋势平滑 | [0.001, α] |
| γ | 季节平滑 | [0.001, 0.999] |
| φ | 阻尼 | [0.80, 0.98] |

目标：最小化**样本内一步预测误差平方和**（SSE），且 SSE 只统计从第
`2m+1` 个观测开始的真正「样本外一步」误差（前两个完整季节用于初值）。
优化器是手写的多起点 Nelder-Mead，在 logit 变换后的无约束空间搜索并以
确定性起点网格运行，因此**同一输入重复拟合结果一致**。锁定的参数从搜索
向量中移除，只优化剩余参数。

### 初始分量（前两个完整季节，文档化的固定规则）

设第 1、2 个季节的均值为 `L0、L1`：

- 初始趋势 `b = (L1 - L0)/m`；
- 初始水平（位于第 `2m-1` 期末）`l = L1 + (m-1)/2 · b`；
- 加法季节初值 `s_i = y_i - (L0 + (i-(m-1)/2)b)`（i=0..m-1），再中心化
  使 `Σ s_i = 0`；
- 乘法季节初值 `s_i = y_i / (L0 + (i-(m-1)/2)b)`，再归一化使
  `mean(s_i)=1`；
- 无趋势时令 `b=0`、基准线为 `L0/L1`。

归一约定在拟合后始终保持（加法季节和为 0、乘法季节均值为 1），
最终状态的季节槽按「槽 0 对应未来第 1 步」规范化。

### SSE 与 AIC

高斯一步误差下：

```
AIC = n·(ln(2π) + ln(SSE/n) + 1) + 2(k+1)
```

`n` 为贡献 SSE 的观测数（有缺周时逐周扣减，缺周不进 SSE；响应字段
`n_effective`），`k` 为被估计的平滑参数个数
（无趋势：α,γ=2；有趋势：α,β,γ=3；阻尼再加 φ=4），`+1` 为误差方差。
自动选型取可行组合中 AIC 最小者。

### 预测与区间

点预测由最终状态直接递推（阻尼用
`b·φ(1-φ^h)/(1-φ)` 累积趋势）。区间两种做法，可在页面选择：

1. **解析近似（默认）**：线性误差状态空间（Gardner 等价误差形式
   `l_t=l_{t-1}+φb_{t-1}+αe_t`、`b_t=φb_{t-1}+αβe_t`）下 h 步预测误差
   方差为 `σ²·Σ_{i=1..h} ψ_i²`，其中

   ```
   ψ_1 = 1
   ψ_h = α + αβ·(φ+φ²+…+φ^{h-1}) + γ(1-α)·𝟙{(h-1) 是 m 的整数倍}   (h≥2)
   ```

   φ=1 时括号内即 h−1；无趋势时去掉 β 项。季节冲击
   `s_t = … + γ(1-α)e_t` 恰好在 m 步后被消费，因此 γ 项每过一个完整季节
   出现一次。该闭式系数已用残差自助模拟数值校准（偏差仅模拟噪声量级）。
   加法模型用绝对残差估计 σ；乘法模型用相对残差 `e_t/ŷ_t`，
   区间为 `ŷ_h(1 ± z·se_h)`。
2. **模拟**：对残差（乘法时为相对残差）做有放回自助抽样，从最终状态
   正向传播 2000 条路径，取经验分位数。

两种方法都**强制半宽随步长单调不减**（累积最大值）——这是预测误差方差
正确累积应有的性质，也可消除自助抽样噪声导致的局部回缩；乘法区间下限
截断在 0。

### 缺周（门店停业 / 系统断档）如何建模

上传时只存**实际观测到的行**；缺周检测列出首尾已观测日之间缺失的周一，
既不阻止导入，也不要求补齐。建模前，后端把观测行展开到一条**稠密周网格**
（首观测周 → 末观测周，每 7 天一格），缺周位置为 NaN 加观测掩码。

**采用的方案：缺周不补值，只做无观测的状态前推。** 网格第 t 周缺测时，
递推执行

```
l_t = l_{t-1} + φ b_{t-1}
b_t = φ b_{t-1}            （等价于普通递推在 e_t=0 时的更新）
s_t = s_{t-m}              （季节槽原样保留）
```

这正是"用当前状态对缺口做多步预测直到下一个观测"的传播：缺周之后的观测
拿到的是跨过缺口的真正多步预测误差。季节槽始终按**日历周** `t mod m` 取，
因此删行不会造成季节相位错位（这正是旧实现 SSE 爆炸、参数撞边界的根因）。

对各项口径的影响：

- **SSE**：缺周不产生残差，不进平方和；残差数组只含有观测的网格周。
- **AIC 的 n**：`n_effective` = 第 `2m+1` 周起**实际观测**的周数（缺周
  逐周扣减）。这些周没有数据，本来就不构成一个似然项，计入 n 只会
  人为压低估计方差。
- **区间宽度**：残差标准差只由有观测周的残差估计；缺周不注入假残差。
  干净序列删三周后第一步半宽仍为 0，未来各步区间与完整序列完全一致。
  含噪序列中，缺口之后第一周的点预测本身是跨缺口多步预测（点预测逻辑
  已天然如此），解析区间的 ψ 权重刻画的是"未来新息"的累积、不受历史
  缺口影响；若缺口很长、希望把跨缺口的状态不确定性也计入带宽，应在
  缺口之后积累若干新观测再预测，或选用模拟法。
- **回测**：原点、留出窗口、季节朴素基准 `y_{k+j-m}`、MASE 尺度全部按
  稠密网格的日历位置取数。去年同期本身缺测时，该朴素点记为不可用并从
  朴素 MAE/MAPE/MASE 中剔除（不猜测、不拿别的周顶替）；原点周或留出
  窗口内任何一周缺测的原点整体跳过，并在结果的 `skipped_origins` 中
  给出原点日期与原因。

**缺口落在最早两年（前 2m 周）内**：拒绝拟合/回测并明确说明——初始
水平、趋势、季节指数的文档化规则需要两个**完整且全部已观测**的季节，
缺周处没有任何可用于初值的信息。可选出路只有两条：补齐该区间，或从
缺口之后重新截取、等其后积累满两个完整季节再建模。注意：删掉**第一
行**（首观测周之前没有数据）属于左截断而非内部缺口，网格从新的首观测
周开始，不受此限。

评估过但放弃的方案：

1. **线性/模型插补后当真实观测**：插补值被当成真实值更新 l/b/s，且平
   白多出 `e=0` 的残差，会低估 σ、压窄预测带、虚增 AIC 的样本数，等于
   用模型自己的猜测给自己背书；
2. **压缩下标、把缺周当不存在（旧行为）**：日历相位被整体平移，`t mod m`
   与季节朴素的 m 步滞后全部错位（干净序列 SSE 36141、朴素 MAE 39.06
   即由此而来）；
3. **直接拒绝带缺周的序列**：停业、断档是常态且往往不可补，拒收等于
   工具不可用。

### 拒绝规则（返回明确原因）

- 乘法季节要求已观测序列全为正：出现 0 或负值 → 拒绝；
- 少于 `2m` 个网格周，或前 `2m` 周内存在缺周 → 拒绝（无法估计初始分量）；
- 递推中水平/乘法季节指数变为非正 → 该组合标记失败并记录原因；
- 自动选型不会静默丢弃不可行组合，评分卡里带原因列出。

## 回测定义

给定起点 `origin_start`、步长 `h`、原点步长 `stride`（所有序号都是
**稠密周网格上的日历位置**，不是压缩后的行号）：

- 对每个原点 `k`，**只用网格上 `k` 之前的已观测周**重新初值化、重新
  优化参数、重新拟合（缺周按无观测前推处理），再预测未来 h 周；
- 原点周或留出窗口内有缺周时该原点跳过（无实际值可评分），并列入
  `skipped_origins`；
- **季节朴素基准**：`ŷ_{k+j} = y_{k+j-m}`（按日历照抄上一季节）；
  上一季节对应周本身缺测时该点不可用，从基准指标中剔除；
- 指标：
  - MAE = 平均绝对误差（仅在有定义的预测点上）；
  - MAPE = 平均绝对百分比误差（实际为 0 的点跳过）；
  - MASE 尺度 `Q = mean|y_t - y_{t-m}|`，只对两端都有观测的、间隔 m
    个日历周的配对取均值（每个原点按其训练段重算），MASE = mean|e|/Q；
- 汇总在全部可用原点/步长上池化计算，逐原点指标也一并给出。

测试用「原点之后注入极端值、预测不变」证明第 k 个原点不使用未来数据。

### 库里已有结果的版本标记

缺周感知修复后的拟合/回测带 `results_version=2`（响应字段 `legacy=false`）。
修复前存入的历史结果没有该标记，API 返回 `legacy=true` 与 `legacy_reason`，
页面历史对比中以红色「旧算法」徽标标出、选中时给出警示条：它们在缺周序列
上是按压缩下标算的，季节相位、原点日期与新结果不可直接比较，重新拟合/
回测即可生成新结果；老记录保留不删除。

## API 摘要

|---|---|---|
| GET | `/api/series` / `/api/series/{id}` | 列表 / 详情 |

| GET | `/api/backtests/by-series/{id}` / `/api/backtests/{id}` | 历史回测 |

`status ∈ pending|running|done|error`，`progress∈[0,1]`。
